## Classification convention used (M2R-FINDINGS-DELTA.md section 1.1, applied to code that did change)

- **SUPERSEDED BY VERIFIED BEHAVIOR (SVB)**: the cause cited by the package is gone from the code at HEAD (file:line given) AND a named test in `backend/tests` exercises the corrected code and passed in my run (Commands 3). Verified on the tests' synthetic input, not on the client originals (originals are not in the repo). If you prefer the stricter reading where FIXED needs no test, every SVB row is also "cause gone"; the FIXED count below would then be SVB + FIXED = 48.
- **FIXED**: cause gone at HEAD (cited), no test in `backend/tests` pins it.
- **STILL OPEN**: cause present or capability absent at HEAD (cited).
- **NOT REPRODUCED**: the decision needs an input that is not in the repository (client original, stored database, labels); stated per row.
- **n/a**: the package itself says it is not a defect.

Test abbreviations (all under `backend/tests/`): `m2` = test_extraction_m2.py; `m2r` = test_extraction_m2_review.py; `m2r2` = test_extraction_m2_review02.py; `m2r3` = test_extraction_m2_review03.py; `pilot` = test_extraction_pilot.py; `r05` = test_m2_review05.py; `r05b` = test_m2_review05_boq.py; `dse` = test_design_sheet_extractor.py; `asr` = test_ai_sheet_reader.py; `ds` = test_document_sync.py; `jt` = test_job_thread_sessions.py; `rep` = test_extraction_repair.py.
